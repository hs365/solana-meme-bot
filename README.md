# Solana 土狗狙击机器人

> 🎯 核心逻辑：只打刚迁移外盘的币
> 24/7 自动追踪 pump.fun 迁移外盘的新币，捕捉大户启动瞬间

---

## 🚀 快速开始

```bash
pip install -r requirements.txt
cp config.env.example config.env
# 填入配置后
bash run.sh
```

---

## 🎯 核心差异：为什么只打外盘？

这是本 bot 与市面上所有土狗机器人的**根本区别**：

| | 内盘（土狗区） | 外盘（Raydium/pumpswap） |
|---|---|---|
| 池子锁定 | ❌ 无锁，增发零成本 | ✅ 第三方锁定，跑不了 |
| rug风险 | ❌ 高，随时可跑 | ✅ 极低，池子已托管 |
| 持币验证 | ❌ 无门槛 | ✅ 经天然筛选 |
| 外部流动性 | ❌ 无 | ✅ 有真实买盘支撑 |

**本 bot 逻辑：** pump.fun 新币迁移到 Raydium/pumpswap 外盘 → 追踪成交量 → 放量时自动买入 → 分批止盈止损

## ⚙️ 配置说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `DRY_RUN` | `true`=模拟盘 `false`=实盘 | `true` |
| `INVEST_SOL` | 每次买入SOL数量 | `0.001` |
| `MIN_LIQ_USD` | 最低流动性门槛 | `$5000` |
| `MIN_HOLDERS` | 最低持币人数 | `80` |
| `TP1_PCT` | 第一档止盈 | `50%` |
| `TP2_PCT` | 第二档止盈 | `100%` |
| `TP3_PCT` | 第三档止盈 | `200%` |
| `STOP_LOSS_PCT` | 止损比例 | `-30%` |
